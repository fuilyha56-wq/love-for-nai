# LFN 联合修复、自审与发布报告

日期：2026-10-17。范围：轻量风控、API阶梯计费、生图首页移动布局。依据：已审核的 `LFN-IMPLEMENTATION-REVIEW-20261017.md` 及本会话追加的 GitHub/服务器发布授权。

## 实现结果

- 新增轻量引擎、七级分值、规则模式与证据族上限；普通观察与明确事实分别处理，固定到期处置及单项解除独立持久化。
- 每日免费授权只检查实际使用个人奖励AFF或零成本免费请求；购买图包、自带供应商独立处理。默认同账号当天一个有效出口，允许两次近期登录确认换绑，间隔15分钟；换绑不重置余额、张数或风险处置。
- 提示词采用HMAC-SHA256精确摘要，支持显式选择SHA256及规范化选项；内存索引有数量和时间边界，不写入原始提示词预览。相同摘要只作为观察，不能证明中转。
- 随机签名设备Cookie、账号令牌桶、同时在途数、消费桶与延迟基线、低频时段分布、明确拒绝及反馈后继续尝试均已接入。
- 上游403、429、5xx、低余额与未知失败不等同于内容违规；拒绝/通过码白名单可配。比例分母只包含明确审核结果；无明确通过结果时该比例并非平台全部请求的违规率。
- VPN/代理、Tor、地区标签使用已缓存资料，不在每次生图请求新增外部信誉查询。N05/R01/G01可由管理员提交独立核验事实，提供原因及内部证据编号，服务端保存编号摘要。
- 用户账号安全页提供免费授权状态、有限换绑和高频申请；后台可审批、撤销限时权限，已有明确风险或手动封禁不会因批准高频而解除。
- 后台提供字段搜索、校验、草稿、导入导出、差异、版本冲突保护、发布和回滚；风控发布与价格配置使用不同接口，风控发布不改价格或免费总量。
- 实际参数及默认值见 [完整配置清单](LFN-RISK-CONFIGURATION-20261017.md)。

## 自审发现及修复

| 发现 | 修复及证据 |
|---|---|
| 旧接口在额度不足/无执行通道时可能换成NewAPI钱包 | LFN计费模型默认严格拒绝；真实账本API测试验证余额及累计张数 |
| 旧调用量/相同Prompt条例可能形成长窗口持续拦截 | 旧条例限制为观察，实际资源保护由令牌桶/在途上限负责；明确违规采用固定期限 |
| 管理写接口缺少统一同源与体积边界 | 同源JSON校验、流式请求体限额、后台二次结构/范围校验 |
| 仅按模块维护锁/缓存存在独立路由状态分离风险 | 账号锁、风险状态、配置、审计及IP缓存改为进程共享；独立模块加载用例验证准入共享 |
| 满容量统计数组可能随账号历史增长而扫描/搬移 | 有界顺序统计树，插入、淘汰和精确计数期望O(log n)；与暴力计数逐条对照 |
| 诊断每次全量写及失败影响请求收尾 | 普通日志批量追加，观察案件批写；基线写失败不丢弃已付费输出；资金与关键处置独立持久化 |
| HTTP账号核验失败或账号停用后仍可能返回身份 | 失败关闭；增加模型授权范围检查，缓存不超过Key有效期；缓存索引只保留Key摘要 |
| 凭据缓存撤销时效不明显 | 默认5秒，可配0逐次验证；负缓存独立可配，后台说明同步延迟 |
| 审计可暴露提示词、上游错误回显及来源查询参数 | 提示词字段隐藏、IP用HMAC、Referer去查询、错误仅留固定分类；用户本人历史仍按归属提供参数 |
| 未知账号请求收尾可能遗留准入上下文 | 所有完成状态释放上下文；容量满不静默跳过免费授权 |
| IP关联、设备缓存及诊断文件可能无界增长 | 索引/关联容量限制、增量清理及按期删除自有诊断/授权文件，保留财务账本 |
| 持久化可信代理开关与部署环境冲突 | 验证入口与端口隔离后，私有备份并同步单一布尔项，避免免费授权误报来源不可用 |
| 动态运行目录被误纳入standalone依赖追踪 | 标记运行时路径，最终构建消除该警告；容器实际检查敏感文件缺失 |
| 前端和旧部署示例出现运维地址 | 改为账号页、服务名/回环示例；私有运维笔记及凭据脚本排除Git和Docker上下文 |

## 明确边界及后续扩展

- 当前实现针对单Node进程。增加副本前需要共享原子存储、分布式租约及跨实例并发测试，不能直接复制容器后声称限额仍一致。
- 签名Cookie仍可清除或由中转转发；固定一个出口的中转仍可能伪装正常账号。该机制提高规模滥用成本，不构成绝对识别证明。
- 稳定作息/消费历史需要积累，异常本身不足以认定恶意；自动等级动作默认关闭，先观察实际分布及误报再调阈值。
- 语义相似模型、外部信誉供应商、人机验证尚未接入，后台不能直接启用；预算字段是扩展契约，不会假装产生检测结论。
- 管理权限沿用项目现有管理员角色；本次未新增细粒度RBAC系统。原始IP查看继续受既有加密及审计开关控制。
- 诊断与短期精确摘要/设备关联可能在进程终止时丢失近期观察；有效处置和当天免费授权落盘后会恢复。账本不会因关闭检测而重置。
