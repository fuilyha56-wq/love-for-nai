# LFN 高强度账号安全与反中转风控方案 V2

日期：2026-10-17。状态：架构与策略提案，未实现、未部署、未对真实账号执行限制。

本版根据“极强账号安全、多方面自主审查、防止账号及 API 被上下游中转”的要求重订。它取代上一版的策略强度和实施优先级；上一版的 IP 唯一记录、地址可信边界、范围过滤与幂等结算细节继续适用。

**1. 目标与严格模式默认值**

保护对象：账号、认证因子、会话、Key、用户资金、赠送额度、上游凭据和平台生成能力。重点对抗批量注册、撞库与接管、会话/Key 泄露、凭据共享、额度套利、内容边界探测、未授权转售及代理链绕过。

推荐上线严格模式：

| 项目 | 默认行为 |
| --- | --- |
| 新账号 | 邮箱验证完成后进入受限观察期；赠送额度有单独消耗上限 |
| 外部 API | 新个人账号默认关闭；完成强认证并获授权后签发独立 API 凭据 |
| MFA | 管理员、代理主体和外部 API 开通强制；个人账号支持 Passkey/TOTP，敏感动作要求近期强认证 |
| 凭据用途 | 浏览器会话、用户 API、合作代理、服务间调用、管理操作分别使用凭据和权限 |
| Bearer 兼容入口 | 明确作为较低保障等级，独立预算和并发；不能因请求格式兼容就继承完整站内身份 |
| 代理能力 | 仅开放给已登记代理主体；普通用户 Key 不具备代客身份传播权限 |
| 资源限制 | 账号、Key、代理客户、关联风险主体、上游通道及全站预算同时生效 |
| 高风险动作 | 自动冻结相关会话/Key/能力与资金消耗，不等待人工看到告警才止损 |
| 封控范围 | 站内、外部兼容、NAI 原生、个人供应商、NewAPI 回退、Gateway 直连均纳入准入或关闭旁路 |
| 自动化权限 | 自动执行可逆隔离、撤销被确认泄露的凭据、限制预算；永久账号处置和大范围网段封禁需复核 |

必须承认的边界：可以提高隐藏转售的成本、缩小盗用窗口、隔离已识别主体，但不能仅靠 IP、指纹或签名百分之百识别所有代理。账号所有者主动在自己的服务器签名并代发请求时，持有证明也无法阻止其运行实时转发服务，因此必须结合授权、限额和行为证据。

**2. 本地代码现状与缺口**

| 本地代码观察 | 对应整改 |
| --- | --- |
| 本地注册分支校验邮箱格式，但未要求邮箱验证码通过 | 本地与 NewAPI 认证模式统一邮箱所有权验证及一次性验证状态 |
| 登录路由内未见统一共享限流调用，已有通用限流器为进程内状态 | 登录、注册、验证码、2FA、恢复、令牌导入共享 Redis 防护；上线前核对边缘/上游已有措施 |
| `/api/auth/token` 验证上游令牌后可以建立站内会话 | 限定导入令牌会话的保障等级和权限；敏感动作不能借此绕过近期 MFA |
| 2FA 转发存在于 NewAPI 登录流程 | 为本地账号及其他认证入口补齐统一 MFA 生命周期，覆盖解绑与恢复 |
| 未发现完整的安全设备关联、临时邮箱/号码信誉、请求内容安全审核日志链路 | 这些属于新增数据能力，不能把未接入的数据标记为安全或假装已有检测 |
| 现有 IP 归属地主要来自本地 ip2region | 位置库不等于 VPN、住宅代理或恶意信誉库，需分别登记情报来源 |
| 风控以重复提示词、高频/高量与本地账号/邀请链封禁为主 | 新增账号接管、凭据、额度、设备、注册、内容及中转的独立判定 |
| 当前封禁动作明确不修改 NewAPI 上游状态 | 落实服务入口隔离、上游策略同步和执行结果对账 |

以上仅是当前工作区的静态观察，不能替代生产配置、安全测试和上游服务检查。

**3. 多方面自主审查架构**

使用八类检测器、按场景决策的策略服务、统一执行器及自动复核任务。它们是服务模块，不要求使用多个大模型代理。

请求链路：可信入口 → 请求/身份上下文 → 已生效限制 → 共享基础限流 → 注册/认证或业务鉴权 → 并行读取风险特征 → 场景评分与确定性规则 → 强验证/拒绝/预算预留 → 入队 → 出队复查 → 上游调用 → 结果审核与结算 → 事后分析。

| 审查时间 | 自主执行内容 |
| --- | --- |
| 每次注册、登录、令牌导入、2FA、恢复 | 来源、账号目标、设备关联、认证保障、尝试速率、已有案件 |
| 每次业务调用 | Key/会话绑定、权限、内容策略、实时速率、并发、预算、代理身份及封控 |
| 事件触发 | 新设备、新 Key、改密/改邮箱/MFA、配额发放、连续拦截、跨来源并发，立即重评 |
| 每 1 分钟 | 消耗突增、突发扇出、异常排队、持续重试、限制执行失败和同步滞后 |
| 每 5 分钟 | 账号—设备—Key—IP—邀请/奖励图谱更新，识别低频分散的协同行为 |
| 每 1 小时 | 个体与同类群体偏差、慢速额度套利、凭据共享、未授权中转案件 |
| 每日 | 基线与规则漂移、情报时效、误报、覆盖缺口、资金与调用对账、权限审计 |

后台任务必须有唯一任务键、租约、断点和重试，重跑不重复加分或重复封禁。已知有效的硬封禁与预算约束直接生效；未校准的启发式先影子执行，再分组扩大自动处置范围。

**4. 数据事实、可信程度与可用性**

每个安全事件至少包含：事件 ID/发生与接收时间、内部账号 ID、会话/Key/代理 ID、业务操作与链路 ID、来源服务、动作及结果、地址角色、设备/客户端标识、认证保障等级、内容结果类别、成本与支付来源、策略/模型版本、可信级别和采样完整度。

信号按四类标注：服务端确认事实、受信入口观测、已认证第三方声明、客户端自报。浏览器指纹、代理声明的客户地址和客户端时钟不能提升为服务端确认事实。

内容结果至少区分：明确策略拒绝、低置信待复核、格式错误、认证失败、额度不足、速率限制、上游策略拒绝、上游故障。不能把全部 403、429 或 5xx 计作内容违规。

未采集、超时、数据过期用 `unknown`，不填 0；单独展示特征覆盖率、情报时间和事件延迟。认证、硬性限制和余额无法确认时停止受保护操作；可选地理/信誉查询故障不自动给用户加罪。

**5. 八个评分维度**

各维度 0–100 分，分别返回分数、置信度、证据、可用性和更新时间。以下权重为待校准初值，总和 100%，不是已验证的生产模型。

| 维度 | 权重 | 核心信号 | 数据来源 | 直接约束 |
| --- | --- | --- | --- | --- |
| Q 额度滥用 | 15% | 消耗速率、已用/可用预算占比、赠送额度快速清空、异常退款重试、跨账号额度协同 | 账单、结算、配额与奖励账本 | 限制资金消耗、冻结奖励结算 |
| B 行为异常 | 10% | 调用时间分布偏差、Prompt 重复/近似度、节奏、并发、端点序列、持续时长 | 请求和队列日志 | 限速、降并发、限制相关能力 |
| D 设备关联 | 12% | 同设备关联账号数、设备切换速度、旧会话跨客户端使用、同客户端反复换号 | 第一方设备标识、可用的公钥证明、边缘观测 | 限制新设备与可疑会话 |
| C 内容风险 | 10% | 明确策略拒绝比例、违规尝试频次、收到拒绝后的持续修改、跨端点重试 | 版本化输入/输出审核结果、明确上游拒绝 | 拒绝请求、暂停相关能力 |
| A 账号安全 | 20% | 撞库、异常会话、敏感资料变更、新设备高额消耗、恢复/解绑异常、凭据泄露 | 认证、MFA、会话、Key 与资料变更日志 | 强验证、撤销会话/Key、保护性冻结 |
| N 网络/地理 | 5% | 新 ASN/国家、代理/VPN/Tor 信誉、出口变化、同时跨地域使用 | 可信入口、归属地与独立信誉数据 | 来源挑战、精确入口限流 |
| R 中转/共享 | 20% | 未授权代理证据、Key 跨主体扇出、持续多客户负载、合作链签名/范围异常、旁路调用 | Key、链路、代理注册、并发和服务间认证日志 | 停止外部 API、隔离代理/凭据 |
| G 注册/团伙 | 8% | 同 IP/设备批量注册、临时邮箱、已接入的虚拟号码情报、注册后同源领赠与消耗 | 注册、验证、邮箱/号码情报、邀请与奖励图谱 | 停止注册批次、冻结待发奖励 |

综合分只用于总体排序，不能让低风险维度冲淡账号接管或凭据泄露。方案采用“综合排序 + 场景评分 + 单维保护 + 确定性规则”四层决策。

综合分按有观测的维度与置信度加权，并另列覆盖率；缺失维度不补零。数据不足的账号采用明确的低信任权限与预算，不通过分母调整伪装成可信老用户。基线异常模型的置信度不足时不输出确定结论。

场景初始配比：账号接管 `50%A + 25%D + 15%N + 10%B`；中转共享 `55%R + 20%B + 15%D + 10%N`；注册套利 `45%G + 25%D + 20%Q + 10%B`；边界探测 `70%C + 20%B + 10%R`。分别决定对应主体和能力，不把所有场景折成一个无法解释的总分。

单维保护示例：额度引擎到达合同预算，直接停止进一步预留；高置信的账号接管证据保护会话及资金；重复明确内容违规暂停生成能力。均无需等待综合分。已撤销 Key、无效服务身份、明确超预算、禁止的路由或无效证明直接拒绝当次请求。

证明重放或外部错误密码只能直接拒绝该尝试；攻击者不能仅靠向受害账号发送错误请求让其账号被永久封禁。

**6. 区分正常高频与滥用**

按账号类型、授权套餐、操作、模型成本、认证保障和历史使用方式分群：站内创作者、合法高频 API、合作代理、新账号、自动化任务。合法自动化不因没有页面访问或鼠标轨迹受罚。

- 同时观察 10 秒、1 分钟、5 分钟、1 小时、24 小时、7 天窗口，另保留 28 天稳健基线；新用户使用同类基线和新账号预算。
- 速率同时计算请求数、实际生成样本、预计/已确认成本、活跃并发和排队占用；放大图与普通请求不能按同等成本放行。
- 消耗速率与个人同时间段基线及同类群体分位比较，设绝对最小量门槛；不能让“从 0 到 1”成为无限倍异常。
- 配额占比区分用户付费余额、购买图包、赠送额度与平台上游预算。正常用完自己购买的额度不等于套利。
- 个人基线采用延迟更新和受信样本，隔离期、已确认攻击和新异常样本不用于训练正常行为，防止慢慢抬高阈值。
- 额度、并发与速率采用共享原子预留，关联账号只有在具备强关联及案件依据时才施加合并预算；IP 共享不能直接导致全部人共用惩罚额度。

示例：长期稳定的授权服务在其预算内每分钟高频调用可正常通过；新注册群体在同设备/领取链关联下短期清空赠送额度，即使单账号低频也可被自动暂停奖励消耗。

**7. 注册、设备与账号生命周期保护**

注册前按来源、网段、设备、邮箱、邀请入口与全站容量限流，所有验证码验证必须服务端确认、一次使用、过期失效。临时邮箱检查采用带版本的信誉列表、邮箱所有权验证及可用的邮件投递结果；不能仅按邮箱域名短或缺少独立 MX 判定恶意，也不能将 Gmail 等地址规则套用所有邮箱。

电话号码只在产品实际启用时接入并规范化；虚拟/VoIP/重复使用情报标记来源及置信度，不能承诺识别所有虚拟号码。当前没有号码采集链路时该项显示未启用，不为凑评分额外收集。

第一方随机设备标识使用签名 Cookie/服务端登记；浏览器/系统/语言/时区等最小必要特征只作为关联辅助。客户端自报、Cookie 清除、指纹碰撞都可能发生。认证公钥能证明相应私钥持有，不能自动证明“一台物理设备”或“一个自然人”；同步 Passkey 也不等于单设备标识。

登录与恢复同时防撞库、单账号爆破和跨账号密码喷洒；按尝试来源/目标/设备复合窗口递进延迟和挑战，对已验证的正常会话保留恢复通道。响应防止账号枚举；不能存储原始密码来关联攻击。

敏感动作包括创建/导出 Key、修改邮箱/密码、MFA 解绑、恢复、可信设备登记、外部 API 开通、代理资料和高价值额度操作。要求近期强认证，必要时复核并设置冷却期；恢复流程不得降级成轻易绕过原有 MFA 的后门。冷却期间保留账户保护提示和受限读取。

令牌导入最多建立明确的低保障会话；启用 MFA 的账号不能仅凭旧上游令牌获得完整管理或敏感动作权限。恢复、改密或凭据泄露后撤销相关会话/Key，提升用户凭据版本；不得只修改浏览器 Cookie 而让 API Key 继续有效。

在平台支持范围内使用 HTTPS、安全 Cookie、CSRF/Origin 校验保护基于 Cookie 的状态修改；登录与权限变化后轮换会话标识。可复制的会话仍按风险重新验证。相关原则见 [OWASP 撞库防护](https://cheatsheetseries.owasp.org/cheatsheets/Credential_Stuffing_Prevention_Cheat_Sheet.html) 与 [MFA 生命周期](https://cheatsheetseries.owasp.org/cheatsheets/Multifactor_Authentication_Cheat_Sheet.html)。

**8. 内容模式与反复触碰边界**

先定义适合 LFN 业务的明确内容规则、类别、例外、审核范围与申诉口径，再实施输入/输出审核。平台规则、安全分类器和上游拒绝必须分别记录。

内容引擎结合明确命中的规则、审核置信度、最近拒绝时间、后续相似/语义近似尝试、跨端点和跨 Key 行为，检测拒绝后持续试探。相似度模型只作关联线索；不能因创作者反复修改同一 Prompt 就认定违规。

拦截比例的分母为被实际审核且成功获得审核结果的业务操作，需达到最低样本量。相同操作的网络重试不重复计违规；系统故障、限流和低余额不纳入。上游笼统返回错误但未说明类别时，不能擅自标成内容违规。

输入高置信拒绝在上游付费前执行；输出审核若失败须按产品规则决定是否交付，已发生的上游成本独立记账。审核服务不可用时，配置要求必审的端点停止新生成，返回可解释状态；未覆盖的格式不能静默跳过并称已审。

可用文本/多模态模型做风险归类、近似聚类和案件摘要，但其输入均视为不可信，禁止内容中的指令调用管理工具或改变策略。模型不持有封禁密钥，处置由版本化策略服务执行。原始提示词/图片的留存按必要性、权限和期限限制，默认保存摘要、类别与指纹。

**9. 防止上下游中转、转售与 Key 共享**

主动收紧凭据可用范围：

| 凭据类型 | 使用边界 |
| --- | --- |
| 浏览器会话 | 站内操作，不作为通用代理 Key；敏感操作要求近期强认证 |
| 用户 API | 独立签发、独立预算/并发/模型/到期时间；不得转送平台 Gateway 凭据 |
| 合作代理 | 显式 `agent_id`，独立服务身份，注册下游客户伪名、预算与转接能力 |
| 服务间凭据 | mTLS/工作负载身份或接收方绑定的短期令牌，只能访问指定服务和能力 |
| 管理凭据 | 独立认证域与审计，禁止用用户 Key 升级获得 |

严格 API 可采用 OAuth 短期令牌加 DPoP 或 mTLS 的发送方约束；对尚不支持的客户端提供受限 Bearer 档位或受控迁移，不声称协议自动兼容。DPoP 校验请求方法/URI、令牌绑定、时效、nonce 与重放缓存；它本身不绑定请求正文，需要内容完整性时采用适用的标准签名协议。依据见 [RFC 9449](https://www.rfc-editor.org/rfc/rfc9449.html)。

这能阻止仅复制令牌、没有对应私钥的使用者；无法阻止合法私钥持有者实时签名中转。后者通过合同授权、单 Key 预算、扇出与多客户负载、跨主体证据、运行时审查处理。浏览器 Origin、Referer、UA、自报设备号、TLS 指纹及无头标签不能独立证明不存在或存在代理。

合作代理上下文带发行方、接收方、代理/客户 ID、trace、有效期和防重放信息。代理声明的终端 IP 单列，不能冒充 LFN 实测 IP；合作深度与防回环仅针对可验证链路，不假装能识别隐藏层数。

平台出站只连接已登记的上游服务，平台凭据按服务与通道隔离；私网上游凭据不进入用户可配置地址。第三方供应商配置变更要求重新验证，并校验解析目标、禁止内网/元数据服务访问及危险重定向；HTTP/SOCKS 环境代理、Tunnel、网关出站同样登记。NewAPI/Gateway 原生端口由私网或服务身份保护，服务间每跳验权，不能只在 LFN 页面上封禁。

R 引擎关注：单 Key 异常多来源并发、不同客户端配置下的持续多客户负载、账号之间轮转规避预算、未获许可的代理声明、服务身份流向异常、停用后的旁路尝试。高频、机房 IP、时段固定或内容多样单独不足以证实转售；对高置信组合证据可直接暂停外部 API 能力并要求主体复核。

**10. 自主处置规则与起始阈值**

下面为严格模式的初始候选值，需结合正常业务回放校准；不是已经测试可直接生产使用的最佳阈值。阈值对角色/套餐分层，但凭据撤销、授权范围和资金上限没有高频用户豁免。

| 规则 | 起始触发条件 | 自动动作与作用范围 |
| --- | --- | --- |
| REG-01 | 同第一方设备 10 分钟出现 ≥3 次新账号注册成功 | 后续注册要求升级验证；暂缓新增账号赠额发放 |
| REG-02 | 同出口 10 分钟 ≥5 次注册尝试 | 挑战/来源限速；共享出口不直接连坐封账号 |
| FARM-01 | 同设备 24 小时 ≥8 个账号，并有相互印证的领赠/邀请消耗关系 | 冻结相关待发奖励和赠额使用 24 小时，自动建案件 |
| AUTH-01 | 同目标 10 分钟 ≥8 次失败，或同来源触达 ≥20 个账号 | 来源递进延迟、挑战；不据外部失败尝试永久锁受害账号 |
| ATO-01 | 新设备/新网络、近期恢复或 MFA 变更、紧接新 Key/高额消耗等独立信号组合 | 冻结敏感动作和相关资金消耗，撤销可疑会话，转强认证 |
| KEY-01 | Key 撤销、权限不符、绑定证明无效或已见 nonce 重放 | 拒绝当次；确认泄露时撤销相关凭据并通知恢复流程 |
| RATE-01 | 任一账号/Key/代理客户超过批准的速率、并发或预算 | 原子拒绝/排队，429 或明确额度状态；禁止换端点绕过 |
| QUOTA-01 | 5 分钟消耗同时超过绝对门槛、受信基线 5 倍及同类 P99，并伴随来源/设备突变 | 暂停新增资金预留 15 分钟，重评 A/Q；已确认硬预算直接拦截 |
| CONTENT-01 | 10 分钟 ≥5 次独立高置信内容拒绝，至少 3 次发生在已反馈拒绝之后 | 暂停相关生成能力 30 分钟，记录类别与后续尝试证据 |
| CONTENT-02 | 最近 30 分钟已审操作 ≥20，明确拒绝比例 ≥40%，且持续拒绝后尝试 | 暂停相关能力 24 小时，自动复核；低置信结果不累计成确定违规 |
| RELAY-01 | 同 Key 10 分钟 ≥3 个独立客户端/网络群并发，叠加未授权多客户或跨账号预算轮转证据 | 自动暂停外部 API 1 小时；要求强验证及用途/代理授权复核 |
| GEO-01 | 新高风险网络信誉或异常跨地域并发，叠加新设备/会话异常 | 强验证或暂停该会话/Key；地区/VPN 标签单独不永封 |
| LOOP-01 | 验证到循环路由、禁止目标、无效服务身份、超合作深度 | 当次拒绝、隔离相关通道；避免继续扣费与递归调用 |
| EVASION-01 | 已确认受限主体用新 Key/端点继续认证调用，并有强身份关联 | 继承对应能力限制，撤销新签发凭据；外部伪造请求不算强关联 |

“客户端/网络群”不能简单等于不同 IP：移动网络换出口、浏览器升级和 SDK 多实例必须按置信度与批准用途解释。内容规则的严重程度应由已公布业务策略定义，以上次数阈值不意味着低于阈值可放行违规请求。

| 场景风险等级 | 通用自动措施 |
| --- | --- |
| 0–29 | 在既定权限和预算内放行 |
| 30–49 | 加强审计、创建观察项，必要时减少新能力发放 |
| 50–69 | 对该场景执行强验证、降并发/缩预算；API 客户端返回可处理的升级认证状态 |
| 70–84 | 暂停对应 Key/会话/外部 API 或奖励能力 1 小时，自动案件复核 |
| 85–100 | 高置信场景执行最多 24 小时的保护性/业务隔离，停止相关消耗并优先复核 |

场景等级用于相应能力，不默认冻结一切；账号接管可同时隔离全部可疑凭据与消费，已验证原用户仍能进入受限恢复页。未到时限前可用强认证恢复被盗风险，但不能仅靠通过 MFA 就清除内容违规、套利或未授权中转案件。

临时隔离到期必须重评，只有新证据或明确仍生效的规则才能续期；防止同一事件被定时任务反复使用导致无限续封。永久处置人工确认，自动隔离无需逐次人工批准。

**11. 关联图谱、规则组合与自动复核**

节点包括账号、凭据、会话、第一方设备、设备公钥、IP、ASN、邮箱标识、代理/下游客户、邀请与奖励、账单操作、Prompt 聚类及通道。每条边记录关系类别、时间、来源、可信度与证据，不将同 IP 直接等同同一人。

强关联与弱关联分开；同一低可信指纹/共享 IP 不得形成可无限扩散的封禁连通分量。批量限制限定最大传播深度、对象数与强证据边，保存实际受影响对象快照。受限主体新签发的 Key 自动继承对应约束；新注册账号的关联需要重新验证。

同一 `(主体, 规则, 窗口, 证据)` 只产生一个可计分事件；同一现象派生的相关信号设置累计上限，不把设备变化、UA 变化、客户端变化当作三份独立铁证。分数随时间和规则有效期衰减，但已确认撤销的凭据不会因分数下降恢复。

自主复核执行：检查证据是否过期/被撤销、认证是否完成、是否命中合作代理/合法高频策略、是否为全站上游故障、是否产生新独立证据、封控是否已在各入口生效。随后自动解除、继续短期限制或提请人工。AI 摘要可辅助，不能修改原始事实或直接执行管理动作。

**12. 封控执行、上游同步与资金保护**

封控对象包含账号/能力、会话、Key、设备登记、代理、代理客户、精确 IP、CIDR、奖励批次和通道。目标、理由、证据、策略版本、起止、来源案件、操作者/自动规则均必须可查询。

账号硬禁、Key 撤销和能力权限优先；其他有效限制取交集。白名单只能豁免其明确对应的规则，不可免除 MFA、账号停用、预算或签名校验。网络白名单要求可信地址，地址未知不能通过。

动作在同一事务持久化本地限制、审计和 outbox；共享缓存按版本失效，队列出队时再检。NewAPI/Gateway 使用拒绝策略同步、凭据撤销与周期对账；每跳记录政策版本，拒绝过期授权。单靠“已发同步请求”不能标为已执行。

初始验收目标可设为：本地限制传播 P95 ≤2 秒；受控服务同步 P95 ≤10 秒、超过 30 秒自动告警并停发受影响身份的新授权；这些是待测目标，不是现有保证。无法确认限制状态的付费入口停止放行；帮助/申诉/恢复保留最小能力。

保护资金不等于没收余额：冻结进一步消费、待结算奖励与可疑赠额，保留资产归属和流水。退款只依据实际执行、产出和产品政策，幂等记账；上游执行不明先对账，不能反复退款/重试套利。已在执行的生成尽可能安全取消，已发生上游成本不能承诺撤回。

解封只撤销对应动作，不能覆盖其他案件、Key 撤销或上游既有手工禁用。保存恢复条件、自动复核结果及上游版本，避免错误恢复权限。

**13. 保留 IP 去重与范围查看要求**

同账号同规范 IP 在保留期内只有一条关联，A → A → B → A 最终两行；重复登录只更新首次/最近时间和独立统计。数据库唯一约束、事件去重及密钥轮换迁移保障一致性；IP 去重不删除会话、请求或真实安全事件。

后台支持精确地址、CIDR、起止地址、时间窗、IPv4/IPv6、登录/调用、用户/Key/代理、风险等级、地理/ASN、地址角色和可信度过滤。统计、分页、关联查询和导出全部在权限过滤后执行；显示不同 IP 数、成功登录数、调用数、关联账号数和被限制次数。

完整 IP 和跨账号查询有独立权限和用途审计；当前本人、授权用户组、指定案件、全站调查的可查看范围分开。代理声明来源、用户访问源和服务器出站地址不能混在同一个“用户 IP”口径中。保存期限按字段与用途配置，界面明确“保留期内”。

**14. 工程落地与验收**

基础组件：PostgreSQL 保存主体、凭据元数据、设备登记、IP 关系、事件、特征快照、场景决策、案件、限制和 outbox；Redis 保存共享速率/预算/并发租约及 nonce；持久队列处理图谱、基线、内容结果、同步与对账。优先复用受控数据库，按实际负载决定是否再引入专用分析存储。

规则配置有草稿、校验、回放、版本、灰度、回滚和执行权限，不能由模型自动改生产权重。审计使用独立写入权限、集中只追加/不可变归档和校验，禁止通过普通管理操作抹掉封控历史；哈希链自身不等于防篡改，仍需独立保存和权限隔离。情报供应商和模型调用分别有延迟、预算和失效策略。

| 优先级 | 交付 |
| --- | --- |
| P0 | 统一可信入口与账号身份、关闭直连旁路、共享认证限流、本地邮箱验证、令牌导入权限分级、统一准入、IP 唯一关系、资金硬预算 |
| P1 | 全生命周期 MFA/恢复、会话/Key 撤销、专用 API 凭据、设备登记、A/Q/R 第一批引擎、自动隔离及上游同步 |
| P2 | 注册/图谱、版本化内容审核、其余评分、范围后台、案件/申诉/自动复核、合作代理身份 |
| P3 | 发送方约束客户端迁移、个体/群体异常模型、慢速协同识别、红队回放与持续校准 |

关键验收至少覆盖：

1. 本地/NewAPI 注册都不能绕过邮箱验证；验证码重放、过期、刷发和并发重复使用无效。
2. 多进程认证限流一致；撞库和喷洒被挑战/限速，攻击者不能用失败尝试永久锁死受害账号。
3. MFA、解绑/恢复、令牌导入、已有 Cookie、系统令牌和 API Key 的权限边界一致；低保障会话不能创建高权限凭据。
4. 仅复制受约束令牌无法调用；证明重放、过期、绑定错误被拒；有意实时签名中转被列为仍需行为防护的边界。
5. 正常授权高频可用；预算无法通过并发、换 Key、换端点、原生协议或通道回退超支。
6. 低频多账号套利被强关联识别；学校/企业共享 IP 或指纹碰撞不会自动造成全体永久封禁。
7. 多次明确内容拒绝后的持续试探被限制；普通改稿、网络重试、429/5xx 和未接入审核不误算违规。
8. IP 地理、VPN 与虚拟号码数据来源/时效可查；缺失数据不伪造安全结论。
9. 可疑新设备消费、恢复后发新 Key、受限账号新签凭据分别触发相应保护；通过 MFA 不清除已确认滥用案件。
10. LFN 封控同步到受控上游，队列出队再检；旧缓存、服务重启、同步失败和直接调用不能绕过。
11. 同一 IP 100 次使用仍一行，真实事件与会话独立，IPv6/映射地址和跨进程写入正确去重。
12. 场景分、置信度、覆盖率和命中理由可解释；单维强风险不被总分稀释，缺失关键特征触发相应受限模式。
13. 定时重跑不重复加分/无限续封；风险衰减不恢复已撤销 Key；解封不覆盖其他有效限制。
14. 临时封控、资金预留、退款、内容审核失败及上游超时可恢复且幂等；不凭封控直接扣除用户已有资产。
15. 图谱/摘要中的提示注入不能调用管理工具；管理员不能无审计批量导出完整 IP 或抹除处置记录。

按场景分别评估拦截覆盖、确认误报率、申诉改判率、账号损失与阻止的消耗、合法高频通过率、决策延迟、同步滞后、证据覆盖率和审核成本。不使用“封得越多越强”作为质量指标。

规则与阈值以脱敏历史回放、合成攻击序列和经授权测试账号验证；本提案没有执行真实攻击、注册批次、封禁、付费生成或线上修改。
