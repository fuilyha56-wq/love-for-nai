# 故事工作台、提示词助手与标签词库

## 故事工作台

打开[故事工作台](/stories)，创建或选择故事，填写标题、梗概、世界设定等可用内容。先选择账号可用的故事模型，再从当前正文继续生成。

需要探索不同剧情时创建分支，明确当前活动分支后继续编辑。切换分支前确认内容已保存；不同分支的正文和上下文不同，不应把切换分支当作撤销最近一步。

故事服务与图像服务可以来自不同配置。图像 Key 能出图，不表示站点必定对外提供通用聊天或故事生成兼容端点。

## 提示词助手

在图像工作台打开助手，选择当前账号可用的助手模型，再输入需要整理的画面描述或修改要求。将助手建议检查后应用到提示词，尤其确认角色、负面词与参考图不被误改。

模型列表来自账号服务与站点可用目录。没有模型或模型暂不可用时，先确认登录状态、分组权限和上游服务；不要在界面随意添加未配置的模型 ID。失败时保留提示，不要重复提交同一任务造成多次调用。

## 标签词库与补全

进入[标签词库](/tags)查找标签、中文解释及相关信息，工作台输入时可使用补全。公开标签元数据和翻译不是模型语义的保证，组合后仍需用实际生成检查效果。

广场标签筛选、NAI 原生 suggest-tags、站内词库和助手建议是不同功能：广场找作品，词库找标签，助手帮助编排内容。联网服务不可用时，可继续手动输入已有提示词。

## 设置与接入

在[设置](/settings)管理外观、工作台布局、助手或服务配置。设备上的外观偏好与服务器管理端点分别保存，不要把换主题当成换服务。

| 站内接口 | 用途 |
| --- | --- |
| GET /api/stories | 读取当前用户故事 |
| GET /api/stories/models | 查询故事可用模型 |
| POST /api/stories | 创建故事 |
| POST /api/stories/{id}/generate | 在当前故事生成内容 |
| POST /api/stories/{id}/branches | 创建故事分支 |
| GET /api/assistant/models | 读取当前用户可用助手模型 |
| POST /api/assistant/tags | 站内助手标签任务 |

这些接口使用正常登录会话并按用户检查权限，字段会随站内功能演进。外部图像客户端优先使用已文档化的 `/ai` 与 `/v1` 图像协议，不要把站内助手任务当成通用聊天补全接口。
