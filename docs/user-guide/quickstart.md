# 快速开始：生成你的第一张图片

本指南按 2026-10-24 的 LfN 功能编写。模型、费用与入口开关由站点配置决定，以当前页面和接口返回为准。

## 1. 登录并确认额度

打开[登录页](/sign-in)。已有账号可使用站点允许的密码或访问令牌方式；新用户选择当前开放的注册方式。开启“注册必须填写邀请码”时，所有注册方式都需额外提供有效邀请码；要求邮箱验证时先获取验证码，开启两步验证的账号还要完成验证码验证。

进入[我的账号](/profile)，确认个人 AFF、图包 AFF 与 NewAPI 余额。签到和奖励入口是否出现取决于管理员配置。没有足够额度时先兑换、购买图包或联系管理员核实账户情况。

## 2. 选择模型和画面尺寸

打开[图像工作台](/image)，从模型菜单选择当前可用模型。NAI 模型适合标签提示词；其他图像模型按自身能力使用自然语言描述。模型列表为空时不要随意填写不存在的 ID，先检查服务和账号分组。

首次尝试可使用一张 832×1216 的 NAI 图片，正向提示词填写 `landscape, blue sky, mountains, masterpiece`。先保持默认采样器、步数和引导强度，确认预计消耗后生成。

## 3. 查看、保存与继续编辑

生成完成后打开预览，选择下载方式。继续调整时复用提示词、Seed 或参数；需要修改局部内容时进入编辑器。不要把预览进度当作最终图片，等待任务完成后再保存。

[图片历史](/history)用于查找可用的生成记录。[图片广场](/gallery)展示审核通过的公开作品，可以搜索灵感并导入工作台；投稿需要填写作者、评级、来源与标签，提交后先审核。

## 手机如何操作

手机页面使用独立布局：通过底部导航切换工作台和账号，从页面操作按钮打开生成参数、参考图或图片菜单。下拉菜单和对话框可触控滚动；文档先显示目录，点标题进入正文，再用“返回目录”回到列表。

## 用自己的工具生成

外部工具无需先保持浏览器登录，但必须使用有效的 NewAPI 图像 API Key。推荐阅读[Aaalice NAI Launcher 接入教程](/docs?slug=launcher-integration)，或使用[OpenAI 图像兼容 API 示例](/docs?slug=openai-compatible-api)。浏览器账号密码与图像 API Key 是两种不同凭据。
