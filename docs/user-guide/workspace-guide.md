# 图像工作台与编辑器教程

## 文生图的基本顺序

1. 在[工作台](/image)选择模型与生成模式，检查页面允许的尺寸和批量数量。
2. 填写正向内容与负向内容。NAI 使用标签时以英文逗号分隔；其他模型是否支持负面词取决于模型能力。
3. 调整尺寸、步数、采样器、Seed 等可用选项。固定 Seed 可帮助比较参数变化，但不保证不同模型或服务版本生成完全相同的图片。
4. 检查报价和余额，再点击生成。任务结束后从预览或历史下载结果。

不可用的控件会随模型隐藏或禁用。不要把 NAI 的角色、采样器和参考参数原样复制给不支持这些能力的模型。

## 角色与参考图

多角色模式中，先写整体场景，再分别填写每个角色的正负向描述和位置。角色参考、精准参考与 Vibe 的用途不同：角色参考关注人物特征；Vibe 用来影响视觉风格或特征；精准参考采用模型支持的参考约束。

上传参考图后调节对应强度，从一张参考、较低强度开始比较结果。总参考数量受服务校验限制，NAI 合计最多 12 张；具体组合还取决于模型。角色负面词与参考图不会自动变成公开广场标签。

## 图生图

加载源图，选择支持图生图的模型，填写希望保留与修改的内容。强度越高通常允许更大的画面变化。先用小尺寸测试，再提高输出尺寸；源图和蒙版应使用接口接受的格式。

## 局部重绘与扩图

进入[图像编辑器](/image/editor)，载入图片并绘制蒙版。NAI 原生重绘的白色蒙版区域表示要重绘，黑色区域表示保留，蒙版尺寸需与源图一致。选择支持重绘的模型和模式，描述目标区域后提交。

扩图先扩大画布并标记新增区域，再执行支持的扩图或重绘流程。普通重绘、Focused Inpaint 和不同模型的能力不同，优先使用界面提供的模式与尺寸建议。

## 图像工具

超分、背景移除、线稿、草图、上色、表情等操作由站点接入的服务提供。先选图片再选工具，确认工具的报价与输出。工具不可用时检查管理员是否配置对应上游；网页有入口不代表所有上游都实现该操作。

独立 NAI 超分仅接受 PNG，输入最大 3,145,728 像素。更大图片的分块超分属于工作台的单独流程，费用和拼接效果以该流程提示为准。

## 参数复用与本机偏好

从历史或广场导入后，先核对模型与参数再生成。广场作者关闭参数公开时，无法据此恢复私有提示词。外观、工作台布局和部分编辑状态保存在当前设备，换浏览器或设备后不一定同步。

手机的参数面板与桌面分栏独立，切换主题不会改变端点鉴权方式。标签补全与助手模型需要可用数据源；联网助手失败时仍可手动输入提示词。
