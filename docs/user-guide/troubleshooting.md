# 常见错误与请求排查

## 先记录这些信息

发生时间及所在时区、站点地址、最终端点、模型、HTTP 状态码、`X-LFN-Request-Id`、客户端版本。保留最小请求参数，删去 API Key、Cookie、系统令牌和不必要的私有图片内容。

## HTTP 状态速查

| 状态 | 优先检查 | 建议处理 |
| --- | --- | --- |
| 400 | JSON、模型动作、尺寸、步数、参考数量、mask | 用一张小图和默认参数复现 |
| 401 | Bearer Key 无效，或站内 Cookie 过期 | 区分接口鉴权，更新正确凭据 |
| 403 | 登录方式关闭、账号/模型权限、风控或账户路径未开放 | 核对站点配置和账号权限 |
| 404 | 地址拼接或部署子路径错误 | 检查是否重复 /ai、/v1 |
| 409 | 登录会话上限、资源版本冲突等 | 按具体 message 处理，必要时联系管理员 |
| 413 | JSON、base64、multipart 或代理体积超限 | 缩小图像、减少参考图 |
| 429 | Key、图包、上游并发或频率限制 | 按 Retry-After 或渐进退避重试 |
| 502 / 503 | 上游连接、超时、能力缺失 | 保留请求 ID，确认服务状态后再试 |

错误码与 message 应一起看，部分上游错误可能透传不同状态。余额足够不表示所有模型都有权限。

## Launcher 连不上

第三方 API 站点填根地址，API Token 填完整 NewAPI 图像 Key，不填 LfN 密码或系统访问令牌。先用 curl 请求 `/v1/models` 和 `/user/subscription` 验证，再测试一张小图。

订阅摘要中的余额是 LfN AFF 兼容显示，不是官方 Anlas。其他 `/user` 账户路由拒绝访问是当前隔离边界，不要向第三方客户端提供上游管理员凭据。

## 流式有进度却没有图片

确认端点为 `/ai/generate-image-stream`、参数 `stream=msgpack`，按四字节大端长度解帧，读取 final 事件中的 PNG 二进制。网络分块不等于协议帧，尾帧不完整需报错。检查代理是否缓冲或提前断开长连接。

先尝试非流式 `/ai/generate-image` 保存 ZIP。非流式成功时再排查流式客户端，不能把 MessagePack 当 JSON 或 SSE 解析。

## 签到与登录问题

图像 Key 不支持直接签到。先正常登录获取 Cookie，请求 `/api/wallet` 确认会话后再调用 `/api/aff/check-in`。两步验证返回 true 时继续完成验证；收到 401 应停止定时重试并重新认证。

站点可关闭某种登录或注册方式，隐藏入口不是 UI 故障。保持登录也可能因闲置、密码修改或管理员清理失效。

## 搜索不到作品或文档

广场只包含已审核作品；多个关键词或标签同时匹配才有结果，先清除分级、标签后重试。文档全文搜索按整段关键词包含匹配，先缩短关键词或重置分类。公开搜索不会查私有提示词。

## 费用和历史不一致

核对时区、模型系列、每日档位、实际成功张数、支付来源以及 Anlas 标注是实际还是估算。Key 请求使用所属用户的钱包，浏览器当前登录的是另一个账号时会看到不同记录。

超时后不要立即重复付费 POST。先检查本站使用记录、客户端保存结果和请求 ID，再决定重试。前端本机缓存、服务端历史和公开广场不是同一数据集合。

## 向管理员反馈

提供可复现的最小步骤、脱敏响应、请求 ID 和时间即可。完整 IP 查询由管理员填写原因并审计；过去没有记录或超过保留期的数据不能补回。不要把任何密钥贴进公开评论、工单截图或 GitHub Issue。
