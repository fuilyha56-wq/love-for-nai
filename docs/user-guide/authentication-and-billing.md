# 鉴权、AFF 与计费说明

## 三种凭据分开使用

图像 API Key：现有 NewAPI Key，通常以 `sk-` 开头，放在 `Authorization: Bearer ...` 中调用 `/ai`、`/v1` 和受支持的客户端摘要。它可以直接出图，不要求保持网页登录。

网页登录 Cookie：正常登录后由 LfN 设置，用于签到、钱包、历史、资料、投稿和故事等站内 API。Cookie 失效时重新登录；不能用图像 API Key 替代。

系统访问令牌：用于 NewAPI 账户服务鉴权，站点允许时可通过令牌登录获取本站 Cookie。它与图像 API Key、登录流程签发的短期 token 各自用途不同，不要混填。

## 扣费从哪里发生

有效图像 Key 会关联所属用户的钱包。通常先使用图包 AFF，再以个人 AFF 补足，单次可以混合支付；两者不足时能否使用 NewAPI 余额，取决于当前严格 API 计费和上游配置。

响应 `X-LFN-Payment-Source` 可能为 `package`、`personal`、`mixed`、`newapi`。最终以[使用记录](/usage)和账号流水为准。分组倍率、模型固定覆盖、原生操作费用和每日策略均可影响价格。

## AFF、Anlas 与 NewAPI 显示余额

AFF 是本站额度；Anlas 是 NAI 消耗或估算的单位；NewAPI 余额按上游 quota 配置换算显示。三者不要直接按同一数值比较。

图包产品价格、每包 AFF、NewAPI 显示换算和每日计费由后台配置，不能把某次价格截图当作永久价格表。[价格页](/pricing)、工作台报价和实际流水用于当前消费判断。

Launcher 的兼容订阅摘要只把个人与图包 AFF 的总额向下取整放入兼容余额字段，不表示官方 Anlas，精确余额仍在本站钱包查看。

## 每日分档

默认每日统计按用户与 NAI 模型系列累计成功图片，北京时间零点切日。Limit 别名合并到对应系列，节约档也有自身基础费用；批量跨档逐张计算。

| 系列 | 默认分档区间 | 阅读方法 |
| --- | --- | --- |
| V4.5 | 1–100、101–200、201 起 | 后续档位增加基础附加或 Anlas 倍率 |
| V5 | 1–50、51–100、101–200、201 起 | 后续档位按当前配置增加总倍率 |

这些是代码默认区间，管理员可修改甚至关闭每日策略。实际报价还结合基础费用、估算 Anlas 和模型固定价，不能只用“Anlas × 一个单价”还原全部模式的收费。

## 失败、部分完成与重复提交

参数会先校验；预留与结算按生成流程处理。请求失败或只完成部分结果时，按实际完成情况结算并退回未使用额度到对应来源；流式以最终图片事件为关键依据。

网络断开不等于服务器未完成。客户端超时后先查记录或请求 ID，再决定是否重试。接口不承诺任意重复 POST 自动去重，盲目重试可能再次生成并计费。

## 奖励与限制

签到、邀请和创作活动按后台规则发个人 AFF，重复签到、重复审核或重复结算不会因此重复领奖。图包分钟限制、图像 Key 限流、模型和账号限制各自存在，余额足够也可能返回 429 或权限错误。

具体签到方式见[账号与自动化](/docs?slug=account-and-check-in)，工具使用见[API 接入总览](/docs?slug=api-overview)。
