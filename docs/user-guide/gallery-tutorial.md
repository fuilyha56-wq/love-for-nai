# 完整教程：投稿、审核与活动奖励

以一个要求 `blue`、`portrait` 标签的活动为例，完整流程为活动规则 → 创作 → 投稿 → 审核 → 公开互动 → 周榜结算。示例规则不代表当前站点一定有同名活动或固定奖励。

![活动配置、作品审核、广场互动和周榜发奖的流程图](/docs/gallery-workflow.svg)

## 投稿者的步骤

1. 打开[创作者工作台](/studio#activities)，阅读活动时间、允许来源、评级、必需标签与奖励规则。
2. 在图像工作台生成自己的作品，或准备活动允许的本地图片。
3. 从历史或广场入口打开投稿弹窗，填写标题、作者署名、正确评级与来源。
4. 添加活动要求的全部公开标签，例如 `blue, portrait`。画面看起来是蓝色不等于自动拥有 blue 标签。
5. 决定是否公开提示词与生成参数，确认图片格式和大小后“提交审核”。
6. 到创作者工作台查看审核状态；通过后才能在公开广场搜索到作品。

本地上传须为含可解析 NAI 参数的 PNG/JPEG，一次最多 20 张、单张最大 20 MB。部分上传失败时查看失败文件提示，不要重复提交已经成功的全部文件。

## 审核通过后

在[图片广场](/gallery)输入作品名或作者，标签筛选加入 blue 和 portrait，选择对应评级即可缩小范围。分享作品链接，其他用户可以查看、点赞、下载或导入工作台。

投稿通过不保证一定有奖励，还需活动时间、标签、来源、评级、次数与预算均符合。多个活动匹配时，投稿奖励只由优先级最高的合格活动发放。

## 管理员的步骤

1. 在[管理后台](/admin)活动管理创建规则，填写公开介绍与详细规则。
2. 设置起止时间、允许评级与来源，要求 blue、portrait，按需排除其他标签。
3. 设置投稿 AFF、每人次数、活动总次数和总预算，决定周榜指标与名次奖励。
4. 保存并启用，审核投稿时核对署名、内容和资格。
5. 检查奖励记录与预算使用情况，使用后台的自动或手动结算入口处理周榜。

周榜按 UTC 周一 00:00 切周，对北京时间是周一 08:00；不要与北京时间零点切换的签到或每日图片计数混淆。

## 为什么没有拿到奖励

依次检查作品是否审核通过、创建与活动时间、来源、评级、全部必需标签、排除标签、个人次数、总次数、预算和周榜最低指标。自动结算上一完整 UTC 周，刚发生的互动不一定属于已结算周。

查看[账号奖励流水](/profile)和创作者工作台状态。管理员重复审核或重复结算不会再次发放同一奖励，缺失时应查规则与流水，不要通过反复点击尝试重复领奖。
