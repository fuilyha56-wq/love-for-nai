# 图片广场：搜索、筛选与分享

[图片广场](/gallery)只公开审核通过的作品。LfN 搜索框、标签建议、分级与排序菜单在桌面和手机均使用站内样式。

![LfN 图片广场搜索与筛选界面，示例数量仅用于说明操作](/docs/gallery-search.png)

## 搜索作品

在“搜索图片广场”输入作品名、作者或公开标签。关键词按空格分词，作品需匹配全部关键词；例如 `blue portrait` 会进一步缩小范围。公开搜索不检查作者的私有提示词或生成参数。

输入后自动查询，不必反复按回车。右侧叉号清空当前输入；下方显示结果数量和当前筛选条件。加载中会显示状态提示，读取失败时可直接重试。

## 标签、分级和排序

“按标签筛选作品”提供 LfN 标签建议，点击建议或用上下键选择后按回车。可以连续添加标签，多个标签用英文或中文逗号分隔；作品必须同时包含选中的标签，标签最多取前 10 个。

“作品分级”支持全部、全年龄、R13、R17、R18。“排序方式”可选择最新发布、点赞最多、下载最多或导入使用最多。R17/R18 作品默认模糊显示，需主动点击查看，也可以重新隐藏。

点击筛选条件上的叉号可单独移除；“重置筛选”会清空关键词和标签、恢复全部分级及最新排序，并回到第一页。“刷新”保留当前条件，重新读取结果。菜单支持 Escape 关闭、上下键移动、Enter 选择和 Tab 离开。

## 查看、导入和分享

点作品进入详情。下载从图片菜单选择；导入按钮把作品带到工作台。作者未公开的参数不会因为导入而公开。点赞需要登录，下载数与导入数在相关操作成功记录后更新，并非图片浏览次数。

分享使用浏览器分享能力或复制链接。手机作品操作集中在图片的更多菜单中。

## 投稿

点击“投稿”，填写标题、作者署名、年龄评级、图片来源与公开标签。可从历史发起本站图片投稿，或上传含可解析 NAI 参数的 PNG/JPEG。一次最多 20 张，每张最大 20 MB。

“公开提示词与生成参数”开关决定其他用户是否能查看这些参数。投稿进入人工审核，审核通过后才公开；活动奖励还需满足活动资格。转载作品应正确填写作者与来源。

## 公开查询接口

`GET /api/gallery?q=blue&tag=portrait&rating=r13&sort=downloads&page=1&pageSize=24`

`tag` 可重复，`tags` 可用逗号分隔；`pageSize` 为 1–100，默认 24。响应包含 `items`、`tags`、`total`、`page`、`pageSize`、`pageCount`。作品数据包括标题、作者、分级、公开标签、点赞数、下载数、导入数及图片地址。

`GET /api/gallery/{id}` 读取作品详情，`GET /api/gallery/{id}/image` 读取可访问图片。投稿、点赞、下载与导入计数接口按各自会话要求校验；公开读取权限不等于可用 API Key 修改作品。
