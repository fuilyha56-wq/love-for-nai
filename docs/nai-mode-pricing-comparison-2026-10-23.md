## Gateway 公式与模式参数

```text
R = max(width × height, 65536)
S = steps；Medium 固定 14
K = 1；Medium 为 1 / 1.06521739
B = ceil(2.951823174884865e-6 × R + 5.753298233447344e-7 × R × S × K)
M = V5 的 1.5，普通模型的 1
T = 图生图 strength（缺省 0.7）
    重绘/编辑/扩图 inpaintImg2ImgStrength（缺省 1）
    文生图及参考生成 1
A每张 = ceil(max(2, ceil(B × M × T)) × uncond_scale)
A请求 = A每张 × N + 5 × P × N + 2 × max(V - E, 0) + 2 × max(V - 4, 0)
```

P 为精准参考数，V 为 Vibe 参考数，E 为本次已编码/已缓存 Vibe 数。官方 Opus 免费抵扣与本站固定档单独判定；完整模型的动态报价不抵扣免费 Anlas。1.5 是官方 V5 算量系数；销售的 1.25 倍只在 AFF / 人民币 / NewAPI 层计算。

动态 `p=50×A请求`，`completion_tokens=0`。符合固定档时 High p=25、Medium p=18、V4.5 p=0（NewAPI 图像适配可能补为 1）。这些固定标记不是 Anlas。

普通画布最多 3145728 px、64 对齐；Limit 最多 1048576 px、28 步、一次一张。Limit 禁止付费工具、精准参考、未编码 Vibe 和超过四张缓存 Vibe，LFN 在扣款前拒绝，Gateway 同时校验。High 每张生成费用上限 140 Anlas 按真实模式与强度校验。

## NewAPI 精确表达式：本轮待同步

旧八条表达式都用 `p < 100` 识别固定档。因此 1 Anlas 工具的 p=50 会误入固定费；High 超分旧收费为 8 余额=¥0.04，新为 5 余额=¥0.025。修改条件后，固定费常数、动态系数、ModelPrice 和分组均保留。

V4.5 Full / Curated / Inpaint：

```text
p <= 1 ? tier("limit", p * 0 + c * 0) : tier("full", p * 80000 + c * 0)
```

V5 High Full / Curated / Inpaint：

```text
p == 25 ? tier("limit", p * 0 + c * 0 + 8000000) : tier("full", p * 100000 + c * 0)
```

V5 Full Medium / Inpaint Medium：

```text
p == 18 ? tier("limit", p * 0 + c * 0 + 3461538) : tier("full", p * 100000 + c * 0)
```

```text
Q=500000 quota/余额单位，S=200 余额单位/人民币
E = 上述表达式的结果
quota = round(E / 1000000 × Q × G)
扣款余额 = quota / Q
人民币 = quota / (Q × S) = quota / 100000000
```

Draw=1、Draw-Limit=1、Draw-Limit-2=0，现无额外 GroupGroupRatio。固定档 High 仍是 ¥0.04，Medium 仍是整数 quota 1730769=¥0.01730769，V4.5 仍为 0；各 Limit 的按次 ModelPrice 保留原值。分档表达式中 p 已含本次总动态 Anlas，不再乘 N。

## LFN 每日阶梯保留

```text
单张 AFF = round4((基础 AFF + (阶梯附加人民币 + 分摊到本张的动态 Anlas × 销售单价 × α) / 0.005) × β)
```

| 模型 | 当日序号 | α 动态倍率 | β 总价倍率 |
| --- | --- | ---: | ---: |
| V4.5 | 全部 | 1 | 1 |
| V5 High / Medium 共用次数 | 1–75 | 1 | 1 |
| 同上 | 76–125 | 1.1 | 1.1 |
| 同上 | 126–200 | 1.15 | 1.15 |
| 同上 | 201 起 | 1.2 | 1.2 |

线上各 V5 阶梯 baseCny 都为 0.04，因此相对首档附加人民币为 0。跨阶梯请求逐张计算，四位 AFF 精度及部分失败退款保留。以 90 Anlas High 为例，各阶梯为 455 / 550 / 600.875 / 654 AFF。
