# 无限画布行为与来源

本次画布会话按 [YILING0013/novelai_local_web](https://github.com/YILING0013/novelai_local_web) 的 `InpaintWorkspacePanel.js`、`workspaceMath.js` 和 `maskUtils.js` 对齐，参考提交为 `d557be6a501957e2962d4ad271102ca6eb91a30a`（2026-11-01 获取）。参考项目采用 AGPL-3.0，本项目采用 AGPL-3.0-only。

## 操作流程

- 画布内容、世界坐标取景框和相机分别维护。取景框越界产生自动蒙版，与用户笔迹合并；完全空白的区域走文生图。
- 生成结果进入候选会话，不立即替换内容。对同一区域再次生成会保留已有候选，所有候选都基于本轮开始时的画布，不在候选之间叠加。
- 单个候选可以直接合并到当前画布。多个候选可以切换比较、指定主结果、保留其他结果，并结束本轮；主结果合入当前画布，保留结果按用户的图像历史设置保存。
- 合并更新图像和世界边界，关闭候选会话并解除编辑锁定，保留用户蒙版和当前相机。接下来可移动取景框继续补全。
- “完成并返回工作台”是单独操作，合并候选不会自动离开编辑器。
- 取景框在图像边缘附近按屏幕 5px 阈值吸附。四边、四角和框内数值输入可独立调整宽高，输出遵守模型的尺寸网格及像素上限。

## LFN 接入

保留 LFN 的统一图像请求、精确选区合成、账号/本地图像历史、版本分支和桌面/手机界面。自动草稿合并连续修改，空闲 3 秒保存，持续编辑至多 20 秒保存一次；隐藏页面、离开和合并结果时刷新待保存内容。版本树仅在初始导入、生成结果和手动命名保存时产生节点，移动取景框、笔迹和参数变化不会新增版本节点。

模型列表按提供方实际返回的 ID 发送请求，显示官方 API 名称；等价别名只显示一次，Medium 和 Limit 保持独立。无限画布允许普通图像模型，分块超分只提供 NAI 普通图生图模型。
