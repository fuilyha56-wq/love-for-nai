# 风控界面改版与 API 图片签名修复

## 界面变更

- 风控页拆为策略配置、调用统计、风险案件、IP证据及高频申请五个分区。已访问的分区保留编辑状态，切换分区不会丢失未发布配置。
- 策略编辑分为检测参数、规则与计分、风险等级、账号例外、账号复核、发布与版本。96项参数按14类导航，支持跨类别搜索、默认值查看及单项恢复。
- 18条规则可编辑名称、模式、加分、上限、冷却、证据有效期、动作和处置期限；七级风险提供独立编辑入口。原有强弱证据、人工处置、权限与服务端校验规则继续生效。
- 账号例外改为结构化表单，支持到期时间和五项可覆盖参数。草稿、导入导出、默认配置、差异比较及历史回滚继续可用；底部固定操作区保留校验、草稿和发布。
- 旧版观察条例放在独立折叠区，保留历史配置和邀请链设置。
- 统计前后端默认最近24小时，默认用户视图。列表移除单独名次列，直接显示用户名和账号ID。时间视图保留时段含义，并显示该时段按当前指标排序的前三位调用用户及用户总数；CSV同步包含用户名。
- 案件显示中文风险等级，风险分数保留至一位小数；支持用户名、ID、信号搜索和等级筛选，每页10条，操作在独立弹窗中完成。
- IP来源区改为独立表格，按最近出现排序，支持用户、ID、地区、证据编号搜索及IPv4/IPv6/未查询筛选，每页10条。归属地查询仅更新对应行，原始IP保持隐藏。当前加载上限为200条，界面明确显示已加载条数。
- 管理页的可信代理就绪状态改为读取实际运行配置，避免只根据环境变量误报。
- 修复生图页在本地AFF不足时错误展示NewAPI价格及自动回退承诺的问题。严格本地计费模型始终展示AFF预计费用、可用余额与缺口；本地额度不足时先解释原因，不再将另一钱包余额误呈现为本模型可用额度。未更改钱包政策或调整任何用户资金。

## 水印调查与修复

现有LFN水印是PNG元数据中的RSA签名，不会显示文字角标。此次沿用该机制，不默认添加可见文字。检查服务器开关已启用且签名密钥文件存在。

发现并修复：

1. 原生ZIP与MessagePack流式响应原先透传，未调用签名写入。现在ZIP中的PNG逐张处理，保留文件名及附加文件；流式响应继续传递进度，仅对最终PNG帧写入签名，保留样本编号和其他事件字段。
2. 普通NewAPI图像转发此前绕过签名写入。可识别账号的Base64或直接图片响应现在经过签名步骤，不改变其原有计费钱包。
3. 签名前的规范JSON原先包含未定义的可选字段，而写入图片的JSON会省略这些字段，导致校验失败。现在规范化与实际JSON序列化保持一致。
4. 同一请求多张JSON图片原先可能使用重复图片编号，现在分配独立编号。
5. 首次并发调用可能重复初始化密钥，旧逻辑也会忽略密钥持久化错误。现在按数据目录共享初始化Promise，创建目录并持久化密钥，损坏或不可读的密钥不会被静默替换。

API响应新增`X-LFN-Watermark`，非流式结果为`embedded`、`disabled`、`skipped`或`failed`。流式头为`streaming`，最终结果写入请求审计。正文修改后移除失效的长度、摘要和实体标签。

本地检查`nai_artist`的图片处理链路：插件解码或解压后直接将原始字节缓存、编码发送，没有主动重绘图片；抽样最近12张缓存PNG均无LFN签名。此次修复位于LFN服务端，没有修改插件配置或批量改写旧缓存。

## 验证与边界

- 浏览器以合成数据预览桌面1280px和手机393px：页面宽度分别为1280和393，无横向溢出；确认最近24小时默认值、用户名显示、IP分页及修改后校验保留编辑内容。
- 临时预览路由已移出源码，不随生产镜像发布。预览阶段Windows Turbopack出现热更新内部错误，页面重新编译后完成验证；生产以独立Linux构建结果为准。
- 新增真实API路由验证：JSON、原生ZIP、原生流式PNG均通过RSA签名及图像哈希校验；使用本地真实AFF账本确认原生计费与每日计数；普通NewAPI转发不额外扣减本地AFF。
- 协议测试覆盖多图独立编号、ZIP附加文件、进度先到达、网络分片、流截断、关闭签名和并发首次密钥初始化。统计测试确认时间桶能够返回实际用户名和调用量。
- 签名不改变PNG像素。重新编码或移除元数据后可能无法校验；旧缓存不会自动补签。只返回第三方URL的响应不主动下载或改写该URL，状态为`skipped`；非PNG文件仍按格式支持情况跳过，不能声称这些文件已经带签名。

最终全量回归709/709通过。首次最终回归中，旧版内部生成测试在5秒默认预算内发生冷编译超时，影响下一项调用计数；最终以15秒冷启动测试预算执行完整回归，全部通过。TypeScript通过；变更核心文件ESLint无错误，工作台及管理页保留原有可访问性/依赖警告。暂存快照扫描532个文本文件，未发现实际凭据、私钥或私有运维地址。

生产构建与线上部署结果随发布完成后补记。
