# 连续局部重绘的画质保护

局部重绘可以保证未选中区域不因反复编辑而累积变糊：将结果按精确蒙版合成回原始像素，保存 PNG，下一轮继续使用原分辨率的合成图。相同区域反复经过模型重新生成时，其细节、线条和画风仍可能变化；此保护不承诺模型生成区域连续十轮保持相同画质，也不适用于整图图生图或主动缩小分辨率。

## 检查结论和修改

- 精细编辑器已有 RGBA 原画、局部贴回与 PNG 保存；本次补上了工作台 NAI 缓冲和流式出口的统一像素保护，包括原生流式、最后预览提升及缓冲回退。保护后的图片同时用于返回和历史记录。
- NAI 请求使用不带透明度的单通道灰度 PNG 蒙版。8×8 模型网格中任意一点被选中时保留该单元，避免细笔迹消失；最终合成仍按原始精确蒙版，网格扩大的范围不会修改未涂抹原画。
- 通用模型出口共用相同保护，软蒙版按预乘透明度混合，透明边界不会因为直接混合 RGB 引入黑边。批量结果顺序处理，限制解码峰值内存。
- 重编码后保留上游 PNG 的有效 tEXt、zTXt、iTXt 参数块，包括 NAI 的 Comment、Description、Software、Source；旧 LFN 像素签名不沿用，由既有出口对最终图片重新签名。

## 验证范围

使用高频线条和彩色细节测试图，连续十轮经过 PNG 编解码、模拟上游模糊、精确蒙版合成，逐轮检查未选中 RGBA 字节，并检查十轮后的未编辑区域。另覆盖编辑器十轮候选应用与整图 PNG 恢复、单像素细蒙版、NAI 元数据、缓冲返回、流式最终图、预览提升、缓冲回退以及历史一致性。测试使用合成图片及模拟上游，不代表十次真实模型生成的画质评分。

对照项目为 [NAI-WorldPainter 的像素合成](https://github.com/sakiko0901/NAI-WorldPainter/blob/5b268007bc3e4b9f77162c82895f53cd878b88ff/lib/domain/services/inpaint_rasterizer.dart)与[NAI 灰度蒙版处理](https://github.com/sakiko0901/NAI-WorldPainter/blob/5b268007bc3e4b9f77162c82895f53cd878b88ff/lib/core/utils/image_utils.dart)。核心做法都是保留原画、只接纳局部生成结果，并把模型所需的请求蒙版与最终合成范围分开处理。
