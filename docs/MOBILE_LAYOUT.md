# 手机端布局与交互

> 本文仅保留早期优化记录，其中抽屉位置和更多菜单等描述已经过后续调整。当前要求是恢复桌面、仅优化手机；实际设备边界和验收结果见 [手机布局与桌面恢复验收](LAUNCHER_LAYOUT_PARITY.md)。

手机工作台采用 Aaalice NAI Launcher 的内容优先、参数抽屉、提示词编辑层、历史与返回层级；保留 LFN 的品牌、主题变量、强调色、AFF 钱包、模型来源及站内功能。参考的是 [v4.3.0 源码](https://github.com/Aaalice233/Aaalice_NAI_Launcher/tree/v4.3.0) 和本机参考仓库的当前实现，没有安装或运行 APK。

## 布局对应

| 区域 | 手机端行为 | LFN 保留内容 |
| --- | --- | --- |
| 创作 | 参数在左、助手在右；预览为主体，提示词与生成操作位于下方 | 品牌、模型名、预计费用与钱包 |
| 参数 | 同一份手机表单管理模型、接口、操作、尺寸、张数、提交方式、采样与编辑参数 | NewAPI、个人 API、NovelAI Key、High/Medium 与模型能力限制 |
| 提示词 | 可滚动编辑层，提供明确的完成、收起与参数入口 | LFN 原有提示词、负面预设、多角色和标签能力 |
| 图片 | 预览直接提供移除参考图片和清空工作区；清空不删除历史 | 图生图、局部重绘、图像编辑器、超分与导演工具 |
| 历史 | 历史／生成／更多切换保留已挂载页面；复用后返回生成页 | 账号、本机、不保存三种设置及完整历史操作 |
| 更多 | 单列文字入口，减少重复链接；公共页面另提供浏览菜单 | 广场、重绘历史、故事、创作者、标签库、用量、账号、设置、公告和溯源 |
| 编辑器 | 手机工具、生成、画布、历史面板；短横屏保持底部操作可达 | 无限画布、精细重绘、分块超分、版本分支与下载 |
| 设置及其他页面 | 共享触屏尺寸、焦点规则、移动菜单和 LFN 色面 | 外观、个人资料、模型与密钥、提示词库以及前台业务页面 |

桌面仍采用各自的 LFN、NovelAI Local、自定义布局。手机端共用参数和生成栏，切换主题只改变外观。短横屏采用预览与模式／提示词并排布局。

## 修复的行为

- 当前结果和参考图片均可移出工作区；移除参考图会清除蒙版并恢复文生图。新上传图片保持已选的重绘模式，避免悄悄变成图生图。
- 手机端现在能显示工作台反馈与错误；参数入口、关闭按钮和主要触屏操作有明确文字或可访问名称。
- 弹层限制焦点，关闭后返回触发控件；键盘视口、屏幕方向和安全区参与布局计算。更多导航移入 portal，避免页面动画裁剪固定弹层。
- 删除历史按记录 ID 定位，失败保留卡片；清空预览与删除历史分开。新生成记录与账号历史合并，避免旧账号列表遮住新结果。
- “仅保存本机”和“不保存”均禁止请求写入账号历史；本机模式刷新不读取账号历史。新保存的本机记录保留尺寸和采样参数。
- 取消初始化请求时重置模型策略和来源刷新标记，避免开发模式重新挂载后模型列表持续为空。
- 外观设置在用户操作时立即持久化，并防止异步恢复覆盖新选择，修复连续切换主题、强调色后快速离开页面可能丢失设置的问题。
- 移除旧的 NAI 空画布隐藏规则，修复空状态下手机导航不可见；修复自定义布局按钮覆盖账号入口、编辑器窄屏顶栏裁剪，以及消息页误显示故事标题。
- 新手指南改为打开当前的手机参数、提示词与助手入口。
- 模型目录搜索框明确保留图标空间并提供可访问名称，避免文字与图标重叠。

## 验证与复跑

浏览器回归脚本：[scripts/check-mobile-ui.cjs](../scripts/check-mobile-ui.cjs)。使用独立浏览器上下文与模拟 API；模拟生成只返回测试图片，删除只操作模拟响应，不调用真实付费接口。

先在一个终端启动使用独立数据目录的开发服务器，临时密钥需至少 32 个字符。不要将这套测试配置用于线上服务。

```powershell
$env:LFN_DATA_DIR = 'E:/love-for-nai/.tmp/mobile/data'
$env:LFN_SESSION_SECRET = '<临时测试密钥，至少 32 字符>'
npm run dev -- --hostname 127.0.0.1 --port 3000
```

在另一个终端使用相同的临时密钥运行测试。Playwright 可来自本机安装；使用捆绑运行时时，将 `LFN_PLAYWRIGHT_MODULE` 指向其 `playwright` 包的绝对路径。

```powershell
$env:LFN_UI_TEST_SESSION_SECRET = '<与开发服务器相同的临时测试密钥>'
node scripts/check-mobile-ui.cjs
```

默认使用 Edge；`LFN_UI_BROWSER_CHANNEL` 可指定已安装的其他 Chromium 通道。`LFN_UI_BASE_URL` 可指定本机端口，脚本拒绝远程地址。`LFN_UI_SCENARIO` 可按名称筛选场景。

覆盖四种主题 × 三种布局，手机宽度 320、390、600、840，以及 844×390 横屏、390×400 键盘视口；另检查 1024、1180、1600 桌面宽度。包括前台 20 个页面／设置分区、图片导入与移除、历史删除失败、本机模式、参数请求、外观持久化和编辑器四个面板，共 37 个场景。截图与当前运行结果写入 `.tmp/mobile-ui/`。

另运行工作台布局、历史合并、历史持久化、图像编辑、外观、设置导航、采样与数值输入的针对性 Vitest 测试，并检查 TypeScript、ESLint 与生产构建。浏览器模拟不等于 Android／iOS 真机验证；真实系统键盘、刘海设备与 APK 尚未实机检查。本次不部署到线上。

2026-10-23 最终结果：37／37 个浏览器场景通过、0 个浏览器运行时错误；10 个 Vitest 文件共 92 项测试通过；TypeScript、改动文件 ESLint、diff 空白检查及生产构建通过。模型目录搜索框的最后修复另在生产模式下通过 320、390 与 844×390 尺寸复核。完整浏览器结果为 `.tmp/mobile-ui/report.json`，该生产模式复核为 `.tmp/mobile-ui/report-page--models.json`。
