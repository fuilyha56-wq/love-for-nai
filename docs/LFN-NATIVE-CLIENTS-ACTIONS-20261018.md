# 原生客户端兼容与规则动作配置

本次处理 Aaalice 生图提示 `No images found in response`、Langbai NovelAI Studio v2.5.7 无法验证账号，以及风控辅助规则动作被固定为观察的问题。沿用现有计费和水印，不修改 NewAPI 模型价格，不清除新的用户标记。

## Aaalice 更新及返回格式

本地参考仓库已从 `24a019b3` 快进更新到官方主分支 `f92ead236506e61812423ef68d70bffa9e671a1b`，源码版本为 4.3.0。此次更新针对源码，不能等同于已替用户安装或操作新版客户端。

最新版 [ZIP 提取器](https://github.com/Aaalice233/Aaalice_NAI_Launcher/blob/f92ead236506e61812423ef68d70bffa9e671a1b/lib/core/utils/zip_utils.dart) 只提取 PNG/JPG/JPEG。LFN 原来接受 WebP ZIP，因而存在服务端成功、客户端找不到图片的可复现缺口。用户截图只提供兜底异常，未取得对应请求的原始响应，不能将此缺口当成所有同名错误的唯一原因。

- 原生请求没有指定图片格式时优先要求 PNG，减少转换成本。
- 收到 WebP ZIP 时逐张转换为 PNG，保留已有 PNG/JPEG 以及 ZIP 中的其他文件。转换后继续嵌入现有 LFN 水印。
- PNG/JPEG ZIP 不重复压缩；支持上游以二进制类型返回 ZIP，也将直接图片响应包装为兼容 ZIP。
- OpenAI base64 回退统一转换为兼容 ZIP。没有图片、损坏 ZIP、HTML 错误响应返回明确的 502，不伪装成成功空包。
- 在本地扣费路径最终确认前完成格式处理；无效图片沿用退款与审计流程。NewAPI 路径仍通过真实生成接口结算，没有加入管理接口直接扣余额的操作。

## Langbai v2.5.7 验证

按用户所用 [v2.5.7 账号配置实现](https://github.com/2786886095/novelai-image-desktop/blob/v2.5.7/src/nai-accounts.ts) 核对，客户端在发请求前就拒绝 HTTP，包括 HTTP 回环地址。使用该版本的实际校验函数验证：HTTP 被拒绝，HTTPS 可通过输入校验。因此截图中的“账号信息或接口地址无效”不能仅靠修改 LFN 返回内容解决，也不代表服务器已经判定 Token 错误。

其 [只读验证流程](https://github.com/2786886095/novelai-image-desktop/blob/v2.5.7/electron/ipc/nai-accounts-validation.ts) 先访问 `/user/data`；401/403 会立即停止，不会继续尝试 `/user/subscription`。本次新增经过 Bearer 身份验证的 `/user/data`，只返回当前 LFN 用户的合成订阅摘要；不代理上游账号详情，不触发生图，也不泄露上游 Token。其他账号管理接口继续拒绝普通外部访问。

服务器现有管理站点已持有匹配公网 IP 的受信任证书，但原先没有转发 LFN。新增受管理的 `/lfn/` 代理扩展，作为原生 API 的 HTTPS 基地址；使用现有证书与其管理路径，不复制私钥、不注册新的证书账户，也不关闭 TLS 验证。

配置方法：在客户端选择“第三方中转独立 API Token”，API 地址填写 `https://<当前服务器公网IP>/lfn`，图片接口地址留空或填写同一地址，使用该账号自己的 LFN/NewAPI Key。这是 API 地址，不是 LFN 网页工作台地址；不要在末尾添加 `/v1`。

`scripts/configure-api-https.py` 默认只读预览。应用前检查原 TLS 站点、应用回环监听及 nginx 语法；仅替换带有本项目管理标记的扩展文件，先备份，平滑重载后验证 HTTPS 免费准入，失败恢复。现有证书的续期管理不在本脚本中重新建立，继续由原管理系统负责。

## 风控动作恢复配置

此前把辅助规则的动作固定为观察，限制了管理员实际配置能力。本次所有规则恢复相同的动作下拉框：观察、限时限流（429）、限时拒绝（403）。运行模式、动作、期限和分值均能保存和发布。

- 默认策略保持观察；只有规则设置为执行模式、选择非观察动作并发布，才执行对应动作。执行动作要求正数期限，受全局最长暂停时间约束。
- 重复提示词、设备/IP、时段等信号的证据类别仍为辅助，改分或改动作不会升级为明确违规事实；按等级综合处置的独立证据条件保留。
- 同步修复时段偏差 B03、消费突增 Q01 的生成后检测：选择动作后会实际建立限时处置，不再只改界面。
- 既有处置在重启后仍生效；处置期间反复请求不会延长本次期限。辅助规则也使用实际证据标识去重，避免空证据组合导致后续动作一直不能触发。
- 此次不替管理员发布更严策略，不修改当前用户资金和调用历史。
